# 参数配置与运行效率参考

> 本文件是 `settings.json` / `models.json` / CLI 参数 / 环境变量的**唯一速查**，
> 以及各后端、各阶段的**运行效率参考**（含 300 章实测数据）。

## 一、settings.json —— 管线唯一配置

所有路径/章数/模型从这里读，改配置不动代码。示例：

```jsonc
{
  "novel": {
    "name": "诡秘之主",              // 书名(用于输出目录与标题)
    "path": "resource/小说.txt",     // 小说 txt 路径; 相对路径按项目根解析
    "chapters": 300                  // 处理章数(决定数据库与产物规模)
  },
  "llm": {
    "backend": "dots3-note",         // 主模型预设名(models.json 里枚举)
    "api_key": "",                   // 留空则从环境变量 LLM_API_KEY 读
    "embed_model": "bge-m3"          // 向量模型(仅 ollama 生效)
  },
  "run": {
    "src_dir": "cloud_fixed",        // 可视化任务读哪个 LLM 产物目录(历史兼容字段)
    "date_suffix": "",               // 空=自动 日期_时间戳 建新目录; 固定值则增量累积进同一目录
    "archive": {                     // 长文本记忆归档(防边际爆炸, 详见 docs/doubt_index_design.md)
      "w_recent": 30,                // 最近 N 章出现过 → 活跃(长程依赖保护)
      "k_freq": 3,                   // 在 ≥N 章出现 → 活跃(非噪声)
      "k_confirm": 2,                // 被后文证实 N 次 → 永久活跃(长程伏笔保护)
      "every": 20                    // 每 N 章做一次代际压缩(mine 前)
    }
  }
}
```

| 字段 | 说明 | 默认 |
|---|---|---|
| `novel.name` | 书名，决定输出目录 `outputs/<name>_<date>/` | `小说` |
| `novel.path` | 小说 txt；相对路径按项目根解析 | `resource/小说.txt` |
| `novel.chapters` | 处理章数 | `50` |
| `llm.backend` | 主模型预设名（见 models.json） | `dots3-note` |
| `llm.api_key` | **不建议写这里**，用环境变量 `LLM_API_KEY` | `""` |
| `llm.embed_model` | 向量模型名（ollama 本地） | `bge-m3` |
| `run.date_suffix` | 空=每次新建时间戳目录；固定值=增量累积同目录 | `""` |
| `run.archive.*` | 记忆归档参数（伏笔跨章保护） | 30/3/2/20 |

## 二、models.json —— 模型注册表字段

每个预设的字段含义：

| 字段 | 含义 | 必填 |
|---|---|---|
| `name` | 展示名（--list-backends / 交互菜单显示） | ✅ |
| `backend` | 协议：`ollama` / `openai` / `anthropic` / `google` | ✅ |
| `base_url` | 厂商端点（openai 自动补 /v1/chat/completions） | ✅ |
| `model` | 模型 ID | ✅ |
| `auth_scheme` | openai 用：`bearer` / `apikey`；anthropic/google 自动 | 云端 |
| `ctx` | 上下文窗口（显示参考 + ollama num_ctx） | 建议 |
| `json_mode` | 是否支持 JSON 模式（response_format / responseMimeType） | 建议 |
| `thinking` | 是否深度思考模型（本库默认注入关闭参数省 token） | 建议 |
| `concurrency` | 建议并发数（`--parallel` 参考值，防限流） | 建议 |
| `cost` | `free` 免费 / `paid` 付费（UI 标注 🆓💰） | 建议 |
| `roles` | 适用角色标签（extract/collect/mine/review/summary） | 建议 |
| `notes` | 备注（是否需 key、特殊注意） | 建议 |

顶层字段：

- `default_backend`：`--backend` 缺省时用哪个预设
- `doubt_index`：质疑指数默认值（0-1，越大推理越激进，**注意这不是模型参数**，是暗线推理的簇触发阈值）
- `routing`：角色 → 预设 的推荐默认（可用 `--role` 覆盖）

```bash
python src/cli.py --list-backends    # 可视化查看全部预设与字段
```

## 三、CLI 参数 + 环境变量

### CLI 参数（`python src/cli.py`）

| 参数 | 用途 | 默认 |
|---|---|---|
| `<任务>` | extract/collect/mine/annotate/review/build/personality/graph/detail/report/rag/viz/analyze | viz |
| `--backend <预设>` | 主模型预设名（18 个内置） | settings.json 的 llm.backend |
| `--role role=预设` | 角色级模型覆盖，**可多次** | 无 |
| `--chapters N` | 处理章数 | settings 的 chapters |
| `--extract-mode` | two/single/v2/attention | v2 |
| `--model M` | 覆盖模型名 | 预设的 model |
| `--key K` | API key（优先于环境变量） | 无 |
| `--out-dir DIR` | 产物输出目录 | 自动 |
| `--src DIR` | 可视化任务读哪个 stage1 产物目录 | 自动 |
| `--doubt-index 0-1` | 质疑指数（覆盖顶层默认） | models.json 顶层 |
| `--parallel N` | collect/mine 场景级并发 | 4 |
| `--genre 类别` | 按类别加载公版体系图（宫斗/修仙/诡秘/系统/灵异/都市…） | 不加载 |
| `--log PATH` | analyze 指定日志 | 最近会话 |
| `--list-backends` | 列出全部预设后退出 | - |

### 环境变量（云端部署 / 脚本化必看）

| 变量 | 用途 |
|---|---|
| `LLM_API_KEY` | **所有云端后端共用的 key 入口**（dots.ai/智谱/DeepSeek/Claude/Gemini 都是它） |
| `LLM_BACKEND` / `LLM_BASE_URL` / `LLM_MODEL` / `LLM_AUTH_SCHEME` | 不配 models.json 时的纯环境变量兜底 |
| `LLM_ENABLE_THINKING` | `true`/`false`，默认关（省 token；深度思考模型必须关） |
| `LLM_ROLE_MODELS` | 角色路由（`review=claude-sonnet,mine=deepseek-chat`），CLI --role 自动注入 |
| `LLM_NUM_CTX` / `LLM_TEMPERATURE` / `LLM_DOUBT_INDEX` | 上下文窗口 / 温度 / 质疑指数 |
| `NOVEL_NAME` / `BOOK_PATH` / `NOVEL_CHAPTERS` | 覆盖 settings 的小说配置（web demo 多任务用） |
| `NOVEL_GENRE` | 类别库作用域（--genre 自动注入） |

## 四、运行效率参考（实测）

> 数据来源：`logs/*.jsonl` 实测 + 使用说明历史记录。**你的耗时主要取决于模型速度与限流**，下方给出量级参考。

### 4.1 各阶段耗时量级（dots.ai 主后端，RPM=60 / TPM=150万）

| 阶段 | 50 章 | 300 章 | 说明 |
|---|---|---|---|
| `extract` 场景抽取 | ~10-20 分钟 | ~1 小时+ | 每场景 1 次 LLM；本地 4b ≈ 95 tok/s |
| `collect` 四维收集 | ~15-30 分钟 | ~1.5-2 小时 | 每场景 2-3 次 LLM，**全流程最大耗时项** |
| `mine` 四维挖掘 | ~5-10 分钟 | ~30-60 分钟 | 簇级批量推理，受结论数影响 |
| `annotate` 创作解析 | **0.8 分钟**（52 场景） | **4.3 分钟**（294 场景） | 实测 0.9s/场景（batch=1） |
| `review` 编辑评述 | ~15s | ~15s | 5 板块各 1 次调用，与章数无关 |
| `viz` 可视化 | ~30s | ~1 分钟 | 纯本地渲染（jieba 词频 + 注入），零 LLM |

**全流程（extract→collect→mine→viz）**：50 章约 30-60 分钟；300 章预计 **1.5~3 小时**（dots.ai 并发 1 限流下）。

### 4.2 各后端速度与成本对比

| 后端 | 协议 | 速度量级 | 成本 | 适合 |
|---|---|---|---|---|
| 本地 `qwen3:8b` | ollama | ~30-95 tok/s（看显卡） | 免费 | 验证/离线/小规模 |
| `groq-llama` | openai | **数百 tok/s（最快）** | 免费额度 | 批量抽取/收集 |
| `gemini-flash` | google | 快 | 免费额度 | 收集/抽取 |
| `glm-4-flash` | openai | 中 | 免费 | 全流程（1 并发） |
| `dots3-note` | openai | 中（RPM=60 限流） | 付费 | 全流程默认 |
| `deepseek-chat` | openai | 中 | 极便宜 | mine/review 高质量阶段 |
| `claude-sonnet` / `gemini-pro` | anthropic/google | 中慢 | 贵 | review 最强评述 |

### 4.3 关键实测数据

- **embedding 批量**：逐条 `/api/embeddings` 2181ms/条 → 批量 `/api/embed` **51ms/条（快 42 倍）**——管线已默认批量 64
- **annotate**：dots.ai batch=1 下 0.9s/场景（300 章 294 场景共 4.3 分钟）；**为什么 batch=1**：dots.ai 对 JSON 数组执行不佳（实测只回 1 个对象），单场景一次调用保完成率
- **review**：5 板块 15s 完成，与书籍规模无关
- **限流**：dots.ai RPM=60 / TPM=150万（按 key），429 自动退避重试 4 次（5s→10s→15s→20s）

### 4.4 提速建议

1. **快模型跑高频**：`--backend groq-llama` 或 `--backend gemini-flash` 跑 extract/collect（免费且快）
2. **强模型只做评述**：`--role review=claude-sonnet` / `--role review=gemini-pro`
3. **控制并发**：`--parallel` 不要超过预设 `concurrency`（dots.ai=1，强模型=2-4，本地=4）
4. **增量复用**：`extract` 有缓存（`data/extract_cache_*.json`），重复跑秒过；`run.date_suffix` 固定值可让 settings_graph 跨次累积
5. **产物复用**：只改可视化不用重跑 LLM——`python src/cli.py viz --src <已有stage1目录>` 纯本地渲染

## 五、参数调优速查

| 你想调什么 | 改哪 |
|---|---|
| 推理深度（结论多/少） | `--doubt-index`（0.3 保守 / 0.5 默认 / 0.7 激进） |
| 抽取模式 | `--extract-mode v2`（默认）或 `attention`（读者注意力动态切分） |
| 长程伏笔跨章记忆 | `run.archive.w_recent` / `k_confirm`（跨章被证实才永久保留） |
| 并行跑多本 | 环境变量 `NOVEL_NAME/BOOK_PATH/NOVEL_CHAPTERS` 覆盖 settings（web demo 就是这么干的） |
| 换书换模型 | 改 `settings.json` + `models.json`，不用动代码 |
| 输出目录固定累积 | `run.date_suffix` 填固定值（如 `20260830_incr`） |

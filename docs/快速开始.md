# 快速开始 · 从零跑通 NovelPedia

> 主 README 只保留 30 秒速览；环境准备、模型矩阵、CLI 全表、参数调优、数据契约、已知取舍全在这一篇。

## 0. 环境准备

```bash
# Python ≥ 3.10 —— 管线仅标准库即可跑通，零第三方依赖（jieba 词频可选）
pip install jieba
```

**本地模式（零成本 / 离线）**：

```bash
ollama pull qwen3:8b      # 抽取 / 挖掘主力
ollama pull bge-m3        # RAG 向量（可选；未拉则自动降级规则切分 + FTS5）
```

**云端模式**：只需 API key（.env 已被 gitignore 硬性排除，key 不入库）：

```bash
set LLM_API_KEY=***       # 通用（DeepSeek / 智谱 / Kimi / OpenAI 兼容端点）
set DOTSAI_API_KEY=***    # dots.ai 独立 key（可选，避免与主 key 互扰）
```

## 1. 放入小说 → 跑全流程

```bash
# 1) 小说 txt 放到 resource/小说.txt（.gitignore 已排除，不入库）
#    或改 settings.json 的 novel.path / novel.name / novel.chapters

# 2) 四条命令（本地）
python src/cli.py extract --backend qwen3-8b
python src/cli.py collect --backend qwen3-8b
python src/cli.py mine    --backend qwen3-8b
python src/cli.py viz     --backend qwen3-8b

# 云端（效果更强）
python src/cli.py extract --backend dots3-note
python src/cli.py collect --backend dots3-note
python src/cli.py mine    --backend dots3-note
python src/cli.py viz     --backend dots3-note

# 3) 双击 output/pedia_<书名>_<日期>/index.html
```

也可以 `python src/cli.py` 进入交互菜单（选后端 + 选任务）；Windows 可直接双击 `run.bat`。

## 2. 多类型模型匹配（models.json）

所有模型集中在 [`models.json`](../models.json) 注册表：

```bash
python src/cli.py --list-backends    # 查看全部预设与能力字段（🆓免费 / 💰付费标注）
```

- **四种协议**：`ollama` / `openai`（OpenAI 兼容，绝大多数厂商）/ `anthropic`（Claude 原生 /v1/messages）/ `google`（Gemini 原生）——`llm_client.py` 已内置适配，**新增厂商只需往 `presets` 加一组**
- **key 不落盘**：环境变量或 `--key` 传入；dots.ai 用独立 `DOTSAI_API_KEY` 防互扰

### 角色路由：一行配平成本与质量

| 角色 | 阶段 | 建议 |
|---|---|---|
| `extract` / `collect` | 场景抽取 / 三维收集（高频短输出） | 便宜 / 快 |
| `mine` | 设定强化 / 人物简历 / 文风（中频长输出） | 中档 |
| `review` | 编辑评述 / 创作解析（低频高质量） | 最强 |
| `summary` | 章纲 / 总结 | 中 |
| `embed` | 向量化（仅 ollama） | bge-m3 |

```bash
python src/cli.py collect --backend qwen3-8b
python src/cli.py mine    --backend qwen3-8b --role mine=deepseek-v3-2
python src/cli.py review  --backend qwen3-8b --role review=claude-sonnet-4-6
```

> 每条命令启动会打印后端摘要（🆓/💰、模型、上下文、并发）；请求失败给中文定位（401=key 无效、403=无权限、404=模型名/端点错、429=限流降并发）。

## 3. 命令行总览

```
python src/cli.py <任务> [--backend 预设名] [--chapters N] [--model M] [--key K]
                     [--role role=预设] [--genre 类别] [--parallel N]
                     [--only 模块名] [--force]
```

| 任务 | 做什么 | 产物 |
|---|---|---|
| `extract` | 分场景抽取（TXT→SQLite，有缓存可秒过） | `data/stage1_v2_<N>_<书>.db` |
| `collect` | Stage1 三维收集（实体注册表/设定/人物/文风采样） | `output/pedia_<书>_<日期>/stage1/*.json` |
| `mine` | Stage2 三维挖掘（设定强化/人物简历/文风分析） | `output/pedia_<书>_<日期>/stage2/*.json` |
| `review` | 全板块编辑评述（专业编辑视角） | `editor_reviews.json` |
| `build` | Stage2 直出（章纲/人物/设定/总结） | `output/pedia_<书>_<日期>/stage2/` |
| `personality` | 人物性格六维向量（雷达图） | `personality.json` |
| `graph` | 知识图谱数据（角色+设定，章节筛选） | `knowledge_graph` JSON |
| `detail` | 拆书详情数据（三 Tab 数据供给） | `detail_data.json` |
| `report` | 本地 vs 云端对比报告 | `final_report.html` |
| `rag "问题"` | RAG 问答 | 控制台答案 |
| `viz` | **一键**：详情页+图谱+报告 → 单页工作台 | `output/pedia_<书>_<日期>/index.html` |
| `analyze` | 跑批日志健康度报告 | 控制台 H1-H5 |


## 5. 参数配置与运行效率

**完整速查**：[参数配置与运行效率.md](参数配置与运行效率.md)。全部行为开关收敛于 `src/config_schema.py`（**运行时覆盖 > 环境变量 > settings.json > 内置默认**），`python src/cli.py --list-config` 打印全表。常用开关：

| 开关 | 配置项 | 说明 |
|---|---|---|
| 省本地 CPU | `EMBED_OFF=1` 或 `embed.off` | 跳过 bge-m3 向量索引/设定向量化（FTS 检索不受影响） |
| 全量重抽设定 | `--fresh` 或 `collect.fresh` | 删除旧 settings_graph 增量，设定全量重抽（全书重跑必须加） |
| 联网搜索 | `EXTERNAL_SEARCH=1` 或 `rag.external_search` | 启用 knowledge_router L3 联网钩子 |
| 类别加载 | `--genre 宫斗` | 按类别加载公版体系域（默认不加载，与原文冲突以原文为准） |

**关键参数速查**：

```bash
--doubt-index 0.5        # 质疑指数：0.3 保守 → 0.7 激进（见 doubt_index_design.md）
--parallel 4             # 不要超过预设 concurrency（dots.ai=1, 强模型=2-4）
--src DIR                # 可视化任务指定读哪个已有 stage1 产物目录（纯本地渲染）
```

**运行效率实测**（诡秘之主 1308 章全量，2026-08-31 跑批）：

| 阶段 | 耗时 | 说明 |
|---|---|---|
| extract 场景抽取 | **167.7 分钟**（10,161 场景块） | 每场景 1 次 LLM（dots.ai 并发 1） |
| collect 三维收集 | **169.6 秒** | 复用已抽取库（免重抽场景） |
| mine 三维挖掘 | **22.6 秒** | 簇级批量推理 |
| **合计** | **≈171 分钟** | extract 占 98% |

- **增量复用**：extract 有缓存秒过；固定 `run.date_suffix` 可让设定图谱跨次累积；`viz --src <目录>` 纯本地渲染不调 LLM
- **省 token**：抽取层产出 actinfo JSON 流比 TXT 原文直出省 42%；云端深度思考强制关闭（防 reasoning 虚高 6 倍）

## 6. 数据源契约（下游消费必读）

产物根目录：**`output/pedia_<书名>_<日期>/`**（`PEDIA_OUTPUT_ROOT` 环境变量可改根；旧仓 `outputs/<书>_<日期>/` 为历史产物仍可读）。

| 数据源 | 路径（相对产物根） | 说明 |
|---|---|---|
| pedia 单页 | `index.html` | 自包含工作台（内嵌以下全部数据） |
| 拆书详情 | `detail_data.json` | 人物/设定/场景/文风结构化数据 |
| 关系图谱 | `graph_data.json` | nodes/edges（alias 归并后） |
| 人物六维 | `personality.json` | 性格雷达图数据 |
| 场景标注 | `stage1/scene_annotations.json` | 场景级拉片标注（若生成） |
| Stage1 库 | `stage1/stage1_v2_<N>_<书>.db` | SQLite 全量数据 |

> 路径与结构变更必须同步本契约表并报备。下游读取时**只换根目录**，相对布局不变。

## 7. 已知取舍

1. 本地小模型偶发吐坏 JSON（自动重试兜底）；10 章实测命中率见 [compare_10ch](../compare_10ch/compare_result.md)
2. 云端 dots.ai 限流，全量跑需耐心（1308 章 extract 约 2.8 小时）
3. 排比/修辞为规则近似检测，数值仅作风格参考
4. 人物重名依赖别名图确定性归并，个别同人可能仍拆分
5. 向量相似度阈值 0.62、`doubt_index` 0.5 为《诡秘之主》实测校准，换书可调
